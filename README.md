# smart-trash-bin# Smart Trash Bin - Waste Classification

This project is a computer vision component of a smart waste
classification system.

The model identifies different types of waste from images using
the TrashNet dataset and a MobileNetV2-based image classification
model.

## Waste Categories

The model classifies images into six categories:

1. Cardboard
2. Glass
3. Metal
4. Paper
5. Plastic
6. Trash

## Dataset

The project uses the TrashNet dataset.

The dataset contains 2,527 images across six waste categories.

The dataset is not included in this repository.

## Model

The classification model uses:

- Python
- TensorFlow
- Keras
- MobileNetV2
- Transfer Learning
